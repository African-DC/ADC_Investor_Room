# Règles ADC
Lire README et docs avant toute modification, ainsi que l'issue active. Branches feat/E##, PR vers main, pas de merge automatique ni force push, pas de déploiement production. TypeScript strict, TanStack Start, React, Tailwind/shadcn, Convex + Better Auth, Resend, R2 privé. Lockfile reproductible après vérification. Zod aux frontières.
Refus par défaut, identité serveur, ACL par room/section/document et capacité, expiration/révocation, deny prioritaire, NDA versionné. Ne jamais croire les rôles du client. Aucun secret, pièce réelle, URL R2 publique, PII dans logs ou preview. MFA admin avant production. SSR protégé, no-store, noindex, tests négatifs.
UX premium fidèle à ADC, FR/EN, mobile/desktop, clavier, reduced motion, états chargement/vide/erreur. Pas de faux succès ni chiffre inventé. Nom et e-mail seuls obligatoires; autres champs facultatifs. CMS brouillon/revue/publié/archivé. Séparer facturé, encaissé, CA comptable et ARR; relier aux preuves, pas de faux justificatif. Notes CRM privées.
Definition of Done: critères de l'issue, lint, typecheck, tests, build réellement exécutés; tests inter-room et révocation, accessibilité, documentation et PR avec preuves et limites. Ne pas clore un ticket sur code non testé.
