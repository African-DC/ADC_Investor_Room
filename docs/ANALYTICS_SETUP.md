# E13 analytics
Default off on both server and Convex; explicit per-room opt-in, withdrawal stops future collection, no access penalty. No IP, device, tokens, search text, duration, names in events. Auth ID retained solely for daily dedup/distinct participants; admin gets aggregated counts only with analytics:read. Section events require exact current published ACL; document events are server authorization, not completed downloads. Admin preview does not emit. No claim of intent or engagement score. Dashboard last 30 UTC days; backend supports 7/30/90. Limit 5000 rows, fails explicitly rather than partial totals. Display excludes >90-day events; internal analytics:purge deletes batches of 200 idempotently, hourly Convex cron invokes the bounded purge; monitor backlog in staging before any activation. Withdrawal doesn't retroactively erase history; deletion request workflow and approved privacy notice still needed. No production deployment or real consent collected. At 200 deletions/hour the cron may lag during high volume; do not activate without measuring throughput and backlog. Tests use synthetic consent, duplicates, cross-room, revoked section and idempotent deletion. Verify that both flags agree before activation.
