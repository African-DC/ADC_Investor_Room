# E08 — private R2 delivery slice (staging only)
ADC_DOCUMENTS_ENABLED (server), ADC_CONVEX_DOCUMENTS_ENABLED (Convex), existing auth and portal flags default false. Shared ADC_DOCUMENT_DELIVERY_SECRET >=32 random chars on server/Convex only, never client. Configure private R2 endpoint/bucket/read-only access keys. No public bucket or presigned URLs. The API gets an authorized immutable document version from Convex after verified identity, room, current NDA, document:read and, for download, document:download. Audit records authorization, not successful delivery. Object key only via server-secret protected mutation; never list it. R2 proxy checks canonical room/hash key, size <=20 MiB, exact SHA-256 and PDF magic before sending. Whole-object buffering, no Range/PDF.js/streaming yet; native PDF viewer, no watermark. Inline viewing cannot prevent saving/screenshots. Never enable with real documents until review, malware scanning, range support and auth E2E.
Trusted staging CLI operations: upload synthetic PDF to private R2 under rooms/<roomId>/<sha256>.pdf using external trusted tool, documents:registerDraft, scan externally, documents:recordScan (records externally supplied verdict; does NOT perform scan), documents:publish by separate operator label, documents:grant for each document read/download. Existing stagingCms:revoke revokes document grants. No browser upload yet; no real scan/keys/provisioning. Metadata/version schema is ready but replacement/version upload is pending. Admin document tab lists authorized room metadata/scan states and allows scoped read/download grants for assigned profiles; upload remains disabled. No object key in admin projection. File access tests require live isolated environment. 

Document DB tests cover invalid key, scan requirement, separate reviewer label, cross-room denial and disabled delivery. These synthetic tests do not prove real scanner or R2 connectivity.
