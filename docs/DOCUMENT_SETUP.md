# E08 — Convex File Storage (replaces R2)
Current architecture: bounded same-origin upload and delivery, Convex native storage. No R2 provisioning, public getUrl, client upload URL or storage ID. Legacy R2 objectKey field and @aws-sdk/client-s3 removed; every document version now requires a Convex storageId whose size, content type and SHA-256 (Convex stores base64, app computes hex; compared via convex/lib/hash.ts) are verified. No real files have been migrated.
Upload: ADC_UPLOAD_ENABLED and ADC_CONVEX_UPLOAD_ENABLED, separate shared ADC_DOCUMENT_UPLOAD_SECRET (32+ chars). Authenticated staging content:edit membership checked before issuing server-only upload URL and before registration. The app validates multipart size <=3 MiB, PDF header and SHA-256, sends bytes to exact configured Convex origin, and registers storageId with _storage metadata checksum/size/type match and unique reference. No raw upload URL returned to browser. Failed metadata commit may leave orphan: reconcile and delete only after proving no references. External malware scan must bind to exact storage version/hash. Scan verdict recording is not scanner integration. Distinct reviewer required. No real files until live scanner/auth validated.
Delivery: ADC_DOCUMENTS_ENABLED and ADC_CONVEX_DOCUMENTS_ENABLED plus portal flags, separate shared ADC_DOCUMENT_DELIVERY_SECRET (32+ chars). App server issues cryptographically random 60s ticket through authenticated mutation, bound to room/user/document/version/download, checked against current published ACL/NDA, audit of authorization. Convex HTTP action /adc/storage/read requires server secret + one-use ticket, consumes ticket and rechecks room, current grant/NDA/version and storage metadata, reads ctx.storage.get. App server checks SHA-256, size and PDF magic then returns no-store bytes, no redirects or bearer URL. Expired tickets purged every 5 minutes in bounded batches. Revocation blocks future requests, cannot recall already delivered bytes. 3 MiB provisional whole-file limit chosen for Vercel function payload; validate live, enlarge only with a reviewed streaming design. No Range. No automatic cleanup of referenced files.
PDF.js local worker, page controls, canvas watermark, no active links/forms. Not DRM; browser receives bytes, accessible text layer/server-side watermark pending. Verify actual synthetic PDFs, security advisories, backup/restore, private delivery, direct HTTP route denial, expired/duplicate ticket and revocation races before release. Old @aws-sdk dependency can be removed via npm uninstall and regenerate lockfile locally; no active R2 code path remains.
