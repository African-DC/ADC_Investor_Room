# PRD — ADC Investor Room
## Objectif
Portail investisseurs ADC, initialement KLASSCI et WOURI. Accueil progressif, pas de divulgation publique. Parcours : accueil → nom/email → organisation/type/rôle (facultatifs) → téléphone/LinkedIn (facultatifs) → demande → magic link → espace autorisé. Pas de mot de passe investisseur. FR/EN, accessible et responsive.
## Accès
Visiteur public; vérifié (contenu de base approuvé seulement); qualifié (grants explicites); due diligence avancée (grants explicites, NDA selon classification). Admin sur invitation avec MFA. Aucun rôle issu du navigateur. Révocation à tout moment.
## Investisseur
Overview éditorial, entreprise, produits, investissement, finances, traction, équipe, technologie, juridique, conformité, documents, Q&A, updates. Recherche filtrée, bibliothèque sécurisée avec version, lecteur PDF, téléchargement conditionnel et filigrane nominatif.
## Administration
Gestion contacts, accès, CMS de blocs traduits, preuves, versions, reviewer distinct pour publication sensible, aperçu selon audience, journal et révision. CRM : pipeline, notes internes, historique, suivi. Q&A privé, notifications, analytics minimales. V2 : GitHub agrégé et assistant IA avec citations et ACL.
## Critères release
E01–E10 validés; installation reproductible, CI, tests E2E et négatifs, restauration documentée, contenu approuvé et rapprochement des chiffres, revue sécurité et accord ADC. Pas de données de démonstration dans les environnements réels.
