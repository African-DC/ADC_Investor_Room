# Vercel Labs UI SDK
Use the requested headless UI SDK, distinct from Vercel AI SDK. Official docs https://ui-sdk.dev/docs/react and repository https://github.com/vercel-labs/ui. Pin @ui-sdk/react and @ui-sdk/core 0.1.0-beta.16 (beta; verify via CI). Shared SearchField uses InputGroup/Input/InputClear; onboarding fields use Input, admin UI uses Tabs and Input. ADC styling stays local. No agent bridge, WebMCP or external model calls. Read installed docs before extending; test keyboard navigation, focus and SSR. Do not auto-upgrade beta. Skill installation command in AGENTS.md, not executed from this connector-only environment.
