# E10 — evidence-backed financial registry
Staging only for administration, via finance:edit and finance:review membership capabilities. Financial read flags ADC_FINANCE_ENABLED and ADC_CONVEX_FINANCE_ENABLED default off. No real values in Git or fixtures. Every metric is a single reviewed snapshot, not an accounting ledger or invoice generator. Kinds separate invoiced, collected, recognized revenue, ARR, forecast, paying accounts, paying sites, pilots, active users, fundraising target and allocation. Integer XOF/count, ISO date range, normalized scope, bilingual definition, evidence 1–10 exact document version IDs. Evidence must remain current, clean and published within same room. Reviewer must be a different authenticated user. Previous published snapshot with same room/kind/scope/period is archived atomically. Never sum overlapping snapshots, scopes, counts or different kinds; no automatic revenue reconciliation. Investor projection requires room and section permission, current NDA, published section, current evidence, and omits evidence identifiers and titles; document permissions remain separate. A clean scan flag is not accounting verification. Reviewer must verify actual source content and methodology. Forecast and fundraising targets are not actual results. No live data seeded. Bounded 100 rows, pagination and signed accounting reconciliation pending. 

Comparable trend chart uses only already-authorized snapshots grouped by exact section, kind, scope, unit and bilingual definition. Rejects overlapping/duplicate periods and mismatched calendar granularity for flow metrics; never sums them. No claim of accounting reconciliation or verified real figures. Chart has visible period and value labels, supports negative amounts.
