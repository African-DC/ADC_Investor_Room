# Design system
Source officielle African-DC/adc-website : public/img/adc-logo.png (copie locale), tailwind.config.ts et app/globals.css (Poppins, Montserrat, Fraunces; foreground bleu nuit). Palette de travail du scaffold à valider avec ADC : fond ivoire, bleu nuit, accent chaud. Pas de nouveau logo. Typographies de repli tant que fonts officielles non intégrées. Inspiration Linear/Stripe/Notion/Papermark sans copie.
Accueil calme, texte éditorial, CTA unique, formulaire progressif avec retour/skip, confirmation claire sans faux succès. Espace privé : sidebar, résumé éditorial, preuves, mobile. Focus visible, contrastes, reduced-motion, navigation clavier, textes FR/EN et états vides/erreur. Recette 360/768/1440.
## Investor Journey (E02/E03)
Public onboarding uses a dedicated full-viewport layout (100vh fallback + 100dvh, min-height not fixed to allow safe scrolling on small screens/zoom/virtual keyboard), centered official ADC square logo, editorial opening, 5 chapters, animated step progress, and directional chapter transitions. The unicorn line is an ambition, not a promised return or valuation. Native Web Audio synthesizes short subtle tones only after explicit opt-in (muted by default, toggle always accessible, no autoplay/asset/network). CSS transitions respect reduced-motion; no continuous audio. Heading focus follows chapter changes, input UI SDK preserved, bilingual, optional fields still optional, no private data exposed. Existing auth behavior retained: optional pre-verification details must be re-entered; no fake email. Responsive tests cover 320x568, 390x844, 768x1024, 1024x600, 1440x900 with screenshots, no horizontal overflow and usable navigation; allow vertical scroll where necessary. No third-party animation library or new dependencies. Validate the actual visual/audio experience in a live preview before release.
