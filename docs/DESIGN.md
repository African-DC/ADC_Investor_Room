# Design system
Source officielle African-DC/adc-website : public/img/adc-logo.png (copie locale), tailwind.config.ts et app/globals.css (Poppins, Montserrat, Fraunces; foreground bleu nuit). Palette alignée sur adc-website : orange ADC #e8590c (accents), #c2410c (boutons, contraste AA), vert #1a5d3a, ivoire #fbf7f2, texte #1a0f06. Pas de nouveau logo. Typographies de repli tant que fonts officielles non intégrées. Inspiration Linear/Stripe/Notion/Papermark sans copie.
Accueil calme, texte éditorial, CTA unique, formulaire progressif avec retour/skip, confirmation claire sans faux succès. Espace privé : sidebar, résumé éditorial, preuves, mobile. Focus visible, contrastes, reduced-motion, navigation clavier, textes FR/EN et états vides/erreur. Recette 360/768/1440.
